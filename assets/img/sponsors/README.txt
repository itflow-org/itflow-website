Sponsor logos go in this folder.

Use the file names set in config.php ($sponsors), e.g. pittpc.png.

Best: a PNG (about 200-250 px tall) or an SVG, cropped close to the logo, on a
transparent background - not a white or grey box around it.

The site sizes every logo to the same visual weight whatever its shape, so a
wide wordmark and a square badge sit evenly on the wall. Logos show in grey and
turn to full colour on hover; in dark mode they show in white.

Until a sponsor's logo file is here, the site shows their name as a text tile
instead, so nothing breaks while you collect them.
